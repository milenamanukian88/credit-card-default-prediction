# Credit Card Default Prediction

A machine learning project developed to predict whether credit card
clients will default on their next payment using customer financial
and payment history data.

## Project Overview

The project analyzes financial information from approximately
30,000 credit card customers.

The goal is to identify patterns associated with credit default and
build machine learning models capable of predicting whether a customer
is likely to default on their next payment.

## Project Workflow

1. Explored and analyzed the customer dataset
2. Prepared the data for machine learning
3. Examined customer payment history and financial characteristics
4. Trained multiple machine learning models
5. Compared model performance
6. Evaluated factors associated with credit card default

## Dataset

The dataset contains information for approximately 30,000 credit
card customers, including financial and payment-related information.

## Machine Learning

Multiple machine learning algorithms were tested and compared to
determine which approach performed best for predicting credit default.
